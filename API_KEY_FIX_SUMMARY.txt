🚀 QUICK START (DO THIS NOW):

  1. Open: https://console.firebase.google.com
  
  2. Click your project, then:
     gear icon ⚙️ → Project Settings → General
  
  3. Find your Firebase config and copy the full apiKey
     (Should look like: AIzaSyDxxxxxxxxxxxxxxxxxxxxxxxxxxxxx)
  
  4. Edit .env.local and paste the FULL key:
     NEXT_PUBLIC_FIREBASE_API_KEY=AIzaSyDxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
     
  5. Restart dev server:
     pnpm dev

  6. Verify it worked:
     pnpm verify

❌ COMMON MISTAKES:

DON'T:
  ❌ Use "AIza..." (placeholder)
  ❌ Copy incomplete key
  ❌ Add spaces or extra characters
  ❌ Use wrong API key (must be Web API key from Firebase)
  ❌ Forget to restart server after editing .env.local

DO:
  ✅ Copy FULL key from Firebase Console
  ✅ No placeholder dots
  ✅ Exact copy-paste, no modifications
  ✅ Restart: pnpm dev
  ✅ Run: pnpm verify
