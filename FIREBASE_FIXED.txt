HOW TO RUN IT:

Choose ONE of these options:

OPTION A: Firebase Emulator (RECOMMENDED - Works Immediately)
──────────────────────────────────────────────────────────────
  No project setup needed. Works completely offline.

  Step 1: Install Firebase CLI (if not already installed)
    npm install -g firebase-tools

  Step 2: In Terminal 1 - Start Emulator Suite
    firebase emulators:start

  Step 3: In Terminal 2 - Start Dev Server
    pnpm dev

  Step 4: Open Browser
    http://localhost:3000

  Step 5: Sign up for account and use the app!

OPTION B: Real Firebase Project (Production)
──────────────────────────────────────────────────────────────
  Requires Firebase project setup.

  Step 1: Create Firebase Project
    https://console.firebase.google.com

  Step 2: Get Your Credentials
    Project Settings → General → Copy Config

  Step 3: Update .env.local
    Set NEXT_PUBLIC_USE_FIREBASE_EMULATOR=false
    Add your 6 Firebase credentials

  Step 4: Start Dev Server
    pnpm dev

  Step 5: Open Browser
    http://localhost:3000
